# 모먼트 카페 키오스크

메뉴 선택, 카테고리 탐색, 주문 수량 변경, 매장/포장 선택과 모의 결제를 연습하는 반응형 웹앱입니다. 실제 결제나 개인정보 입력은 없습니다. 주문은 새로고침하면 초기화됩니다.

## 실행

Node.js 18 이상과 Python 3가 설치된 환경에서:

```sh
npm start
```

3000 포트에서 실행됩니다. 별도 패키지 설치, API 키나 데이터베이스는 필요하지 않습니다.

## 검증

```sh
npm test
```

브라우저에서 메뉴를 담고 수량을 조절한 뒤 결제하기 → 모의 결제 완료하기를 누르면 주문 번호가 표시됩니다. 카테고리, 매장/포장 선택과 새 주문도 확인할 수 있습니다.
