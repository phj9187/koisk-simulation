# 실시간 모델 비교

`run_live`는 기본적으로 모델 카드 화면을 표시한다. 매장 8개 × 고정 평가기준 9개 × AI 2종으로 144개 신경망 쌍을 구분한다. λ는 같은 신경망의 조건 입력이므로 독립 모델 개수에 중복 계산하지 않는다.

카드에는 AI와 미추천의 점수를 함께 표시한다. 검색·매장·평가기준·AI 유형 필터와 정렬을 제공하며, 클릭하면 확대 화면으로 전환한다. 상세 화면은 고객 만족도 C, 가게 만족도 S, 종합 효용 R, α·β·λ, 최근 추천 가중치, 단계와 최근 결과를 표시한다. λ별 조회와 학습/검증/평가 구간 필터가 있다. 목록으로 돌아오면 이전 스크롤 위치를 복원한다.

비교는 같은 날짜·매장·평가기준·λ의 미추천 결과를 짝지어 계산한다. 기본 순위는 가장 최근에 **전부 완료된 동결 평가 주기**에서 평균한 ΔR이다. 부분 날짜와 학습·검증 결과는 실시간 경향만 표시하며 순위에 섞지 않는다. 평가가 아직 없으면 평가 대기로 표시한다. 서로 다른 α·β는 효용의 의미가 다르므로 기준별 필터를 함께 사용한다. 이 값은 가상 고객 함수에서 계산한 효용으로 실제 사람을 조사한 만족도가 아니다.

화면은 5초마다 갱신한다. 날짜 도중에는 저장이 끝난 매장 결과를 잠정 표시한다. 그래프는 조건별 최근 600개 관측으로 제한해 화면을 가볍게 유지하고, 전체 원본은 날짜별 parquet에 보존한다. `live/cards/points_######.json`, `board_index.json`, `model_board.html`, `status.json`도 Drive에 저장한다. 상세 조회는 실행 중인 코랩 커널의 읽기 전용 서버를 이용한다. 서버는 임의 파일 경로나 실행 명령을 제공하지 않는다.

현재 노트북 기본 종료 시각은 2026-10-29 18:00 KST(09:00 UTC)이다. 일수 상한과 수렴 조기 중지는 이 시간 제한 실행에서 적용하지 않는다. 시각 확인은 매장 작업 사이에 이루어지므로 마지막 매장 처리와 저장은 종료 시각을 조금 넘길 수 있다. 코랩 연결이 끊기거나 제공자가 커널을 종료할 가능성은 남으며 저장된 체크포인트로 재개한다.
