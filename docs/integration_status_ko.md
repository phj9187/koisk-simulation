- GitHub phj9187/koisk-simulation 읽기 접근은 성공했으나 원격 refs는 비어 있다.
- 로컬에는 앞서 만든 카페 웹앱 파일이 있으며 기존 연구 Python 코드는 없다.
- 로컬 브랜치는 work이고 커밋은 없다. 커밋·푸시는 수행하지 않았다.

- 먼저 만든 Python 초안은 기존 알고리즘과 다른 정책경사 방식이었다. 연구 연속성을 위해 실행 경로에서 분리하여 /workspace/scratch/kiosk-provisional-20261014 에 보존했다. 미완성·미검증 초안이며 실제 연구 구현이 아니다.
- 기존 웹앱도 연구용 Colab 시뮬레이터가 아니다. 원본 보존을 위해 유지한다.
