# 시간 제한 없이 푸드코트 학습 이어가기

`notebooks/run_foodcourt_until_complete_colab.ipynb`를 사용한다. 기존 `foodcourt_research_20261103_001` 폴더에서 완료한 작업을 건너뛰고 저장된 세대부터 모든 작업과 최종·스트레스 평가가 완료될 때까지 실행한다. 프로그램의 12시간 제한과 최대 작업 수 제한을 적용하지 않는다.

기존 실험의 시뮬레이션·학습 엔진과 설정은 변경하지 않았다. 별도 실행 스크립트가 기존 엔진을 제한 없는 종료 시각으로 호출하므로 이전 체크포인트와 manifest를 그대로 검증·사용한다. 설정이나 연구 코드가 다르면 재개를 거부한다. 매 세대의 중간 저장 방식도 유지한다.

새 로그는 `training_until_complete.log`, 재개 정보는 `launch_resume_20261104.json`에 남고, 이전 `training.log`와 최초 `launch.json`은 보존한다. `training_status.json`에는 실행 중/완료 여부와 저장된 학습 세대가 표시된다.

실행을 누르면 Colab이 실행 중인 동안 남은 작업을 계속 처리한다. Colab 자체에서 런타임을 종료하거나 연결·자원을 회수하면 같은 노트북을 다시 실행해야 한다. Google 계정 인증은 사용자가 직접 완료한다. 이 실행본은 Colab의 제한을 우회하거나 자동 재접속하지 않는다.

관련 검증 9종이 통과했다. 중간 세대에서의 재개와 처음부터 실행한 결과가 같음, 완료 작업 건너뛰기, 기존 manifest 보존, 설정 불일치 차단, 병렬 실행을 확인했다.
