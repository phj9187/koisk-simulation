# λ 조건부 추천 함수와 파레토 연구 방법

## 가중치 세 층의 분리

1. 만족도 구성 가중치: 고객의 맛·가격 여유·대기, 가게의 이익·잔여 재고 감소를 결합하는 가정.
2. λ: 고객·가게 선호 비율. 두 모델이 함께 사용하는 하루 학습 보상 `Rλ = λC + (1−λ)S`.
3. 추천 가중치 w: 메뉴 적합도·재고 위험·마진·대기를 얼마나 반영할지 학습하는 정책 출력.

정책은 만족도 구성 계수나 λ를 유리하게 변경할 수 없습니다. 기본 세 시나리오는 실측이 아니라 민감도 분석을 위한 가정입니다. Colab JSON/YAML로 수정할 수 있습니다. 고객 유형별 실제 만족도 추정에는 설문·선택·재방문 같은 외부 자료가 추가로 필요합니다.

## 새 함수와 학습

고정 모델: `softmax(Θ [1, 2λ−1, (2λ−1)²])`, 매장·시나리오별 12개 파라미터. 매장과 λ가 정해지면 모든 고객에게 같은 가중치를 사용합니다.

상황별 모델: 위 λ 기저와 고객 취향·가격/대기 민감도·방문 목적·재고압력·조리혼잡 특성의 곱을 입력으로 사용합니다. 108개 파라미터이며 실제 추천에 사용할 네 가중치를 출력합니다. 기존 LinUCB의 메뉴 직접 선택이나 톰프슨 샘플링을 사용하지 않습니다.

매 학습일에 incumbent와 perturbation 후보를 같은 외생 고객·도착·선택 충격·초기 재고·λ 묶음에서 실행하고 평균 Rλ가 높은 후보만 채택합니다. 기본 묶음은 λ=0,1과 균등 내부 표본 하나입니다. 모든 λ를 공동 학습하므로 각 λ의 개별 최적값을 보장하지 않습니다. 파라미터를 ±8로 제한하고 차원 제곱근으로 탐색 이동량을 정규화합니다. 동일 호출 예산은 같은 난이도·계산시간을 뜻하지 않으므로 시간과 호출 수를 별도 기록합니다.

## 성과 구성과 정규화

고객 요소는 선택 메뉴의 기존 affinity(취향·방문 목적 적합도), `max(0,1−가격/예산)`, `τ/(τ+총대기시간)`입니다. τ 기본 25분, 총대기는 도착부터 준비 완료까지입니다. 요소 합계를 전체 방문자 수로 나누어 미응대 고객은 0으로 처리합니다.

가게 요소는 실제 이익을 `방문자 수 × 매장 메뉴 중 최대 단위 마진`으로 정규화한 값과 `1−기말 위험가중 재고/기초 위험가중 재고`입니다. 위험계수는 같은 재료 메뉴들의 평균 expiry_risk입니다. 재고 감소는 실제 유통기한 폐기 손실을 관측한 지표가 아닌 대리 지표이며 단순 판매량과 연관됩니다. 모든 요소는 [0,1] 범위입니다. 실험마다 새 관측 최솟값·최댓값으로 점수를 재정규화하지 않습니다.

방문자 0 매장은 기록을 보존하고 고객·가게 점수를 0, eligible=false로 저장하되 학습·성능 비교에서는 제외합니다. 서로 다른 만족도 시나리오의 점수나 하이퍼볼륨을 동일한 사회적 효용으로 비교하지 않습니다.

## 환경과 공정 비교

원본 매장·고객 생성 및 취향/선택 가정 일부를 재사용합니다. 새 시뮬레이터는 구성요소와 실제 기말 재고를 기록합니다. 예산·알레르기·재고 제약, 키오스크와 조리 대기를 반영하고 원본의 명시적인 방문 목적 시간대 형태를 사용합니다. 구버전과 도착 혼합·만족도 수식이 달라 수치를 직접 동등 비교하면 안 됩니다.

각 모델·λ·시나리오는 같은 외생 조건에서 시작하고 이후 재고·대기는 독립적으로 바뀝니다. 재고는 매일 초기 템플릿에 0.65~1.10 배수를 적용해 다시 생성합니다. 재고 이월/납품 최적화는 구현하지 않습니다. 시드·날짜·매장·용도별 해시로 난수 스트림을 재생성하여 실행 순서·작업자 수와 무관하게 재현합니다.

## 동결 평가와 파레토 비교

반복마다 초기 모델부터 학습→동결 검증→동결 최종 평가를 진행합니다. 이전 반복 파라미터를 다음 반복으로 이어 학습하지 않습니다. 날짜는 분리되며 같은 매장 표본에 조건부인 독립 반복입니다. 매장 표본 자체의 불확실성이나 새로운 매장으로의 정책 일반화를 검증한 것은 아닙니다.

검증 λ 기본 0,.25,.5,.75,1, 최종 λ는 1/8 간격입니다. 내부 연속 학습 표본에서 격자점 보간을 평가하나 끝점은 학습에도 포함됩니다. 검증과 최종 λ 일부는 같고 고객 날짜가 다릅니다. 검증에서 선택한 λ를 최종 평가에서 확인할 수 있도록 최종 격자는 검증 격자를 포함해야 합니다.

학습 종료 후 파라미터는 갱신하지 않습니다. 초기 균등 정책도 동일한 평가 날짜에 실행해 학습 전후를 비교하며 향상을 가정하지 않습니다. 학습 중 후보 선택 점수는 낙관적일 수 있으므로 최종 성능으로 사용하지 않습니다.

최종 성과 쌍으로 비지배 후보와 고정 기준점 (0,0)의 2차원 하이퍼볼륨을 계산합니다. 가게·날짜 행을 독립 반복으로 세지 않고 반복별 하이퍼볼륨 차이를 비교합니다. 5회 미만은 기술통계, 5회 이상은 paired bootstrap 95% 구간을 제공합니다. 완전히 끝난 최종 평가 반복만 통계에 포함합니다. 가중합은 비볼록 전선 일부를 놓칠 수 있고 유한 탐색과 정책 표현력도 제한이므로 전역 최적 파레토 전선이라고 주장하지 않습니다.

## 함수·매장 특성·λ 추천

학습 완료 파라미터와 표준 고객/매장 초기 상태에서의 λ별 가중치 곡선을 저장합니다. 곡선은 전체 상황별 정책을 대표하지 않습니다. 매장별 성과와 특성에 대해 최소 6개 고유 표본이 있으면 표준화 ridge 회귀와 donor-group 교차검증 오차를 제공합니다. 같은 조사 donor를 재표집한 매장들은 같은 검증 그룹으로 묶습니다. 이 분석은 탐색적 연관이며 인과효과나 실제 신규 매장 전이 검증이 아닙니다.

최소 고객 만족도 같은 운영 목표를 지정해야 λ를 추천합니다. 완전히 끝난 검증 날짜에서만 후보를 선택하고 해당 최종 평가 성과를 함께 표시합니다. 객관적·유일한 최적 λ는 주장하지 않습니다.

추후 개별 λ 최적화 기준선, 다목적 베이지안 최적화, 적응적 λ 표본, 제약 최적화, 실제 만족도 피드백, 매장 간 통합 학습, 특성 개입 실험을 별도 비교할 수 있습니다. 신경망/양자컴퓨터 적용은 이번 구현에 포함하지 않습니다.
