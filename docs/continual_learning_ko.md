# 누적 학습 실행

`screening_continual.yaml`은 8개 가상 매장과 9개 평가 기준에서 고정·상황별 정책을 계속 학습합니다. 20일 학습 후 5일 검증·5일 평가 동안 정책을 고정하고, 다음 주기에 같은 정책과 누적 최적화 횟수를 이어갑니다. 주기는 독립 반복이 아니므로 주기 간 부트스트랩 신뢰구간을 계산하지 않습니다. 연구용 독립 반복은 기존 research 설정을 사용하세요.

Colab 자동 노트북에서 PRESET=continual로 실행하세요. 첫 실행은 새 실험을 만들며 기존 pilot 결과를 변경하지 않습니다. 모델과 날짜별 체크포인트, 매장별 부분 저장, 주기별 요약을 Drive에 저장합니다. 이 모드는 이전 체크포인트를 삭제하지 않습니다. 자동 정리는 기본적으로 꺼져 있습니다.

재개하려면 새 실험의 progress.json에 기록된 git_commit을 REVISION으로, experiment_id를 RESUME_ID로 지정하세요. 이전 프로세스가 종료됐는지 확인하기 전에는 RUNNING.lock을 제거하면 안 됩니다. 코드 및 라이브러리 버전이 다르면 재개를 거부합니다. 기존 완료 pilot은 원래 커밋에서 보존하며 누적 실행의 초기값으로 사용하지 않습니다.

Colab이 런타임을 종료하면 학습도 중단됩니다. 연결 유지 우회를 사용하지 않습니다. STOP 파일은 하루 경계에서 중지하며 DAY_BUDGET으로 실행 일수를 제한할 수 있습니다. 가상 날짜는 실제 24시간이 아닙니다. 가상 결과는 실제 고객 만족도의 실증 검증이 아닙니다.
