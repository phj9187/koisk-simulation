# 실행 검증 기록 — 2026-10-18

Cloud Codex의 실제 Python 3.12 실행 환경에서 의존성을 설치하고 검증했습니다. 외부 인증 성공과 로컬 모의 검증을 구분합니다.

## 통과

- 22개 자동 테스트: λ 조건부 가중치, 동일 외생 조건, 평가식 분리, 파레토/하이퍼볼륨, 체크섬, 평가 중 파라미터 동결, 동일 호출 예산, 재개 재현성, 하루 경계 중지, 매장 부분 복구, 손상된 최신 체크포인트의 이전 세대 복구, 중복 방지, 설정 변경/중복 실행 거부, 0명 매장, 독립 반복 초기화, 제약 기반 선택, 토큰 누락/401 처리, GitHub 새 브랜치 API 모의 검증, 2 CPU 작업자 결과 일치, 반복 단위 bootstrap, 실제 기말 재고/상세 기록, 위젯 비동기 실행/중지 콜백, 원자료 해시 오류 거부, 노트북 Python 문법 및 원본 소스 21개 해시 보존.
- 가상 매장 8개 × 하루 15명, 학습 2일·검증 1일·최종 평가 1일, 만족도 가정 3개, 모델 2개인 스모크 실험 실행.
- 일별 결과 960행, 모델별 시뮬레이션 호출 960회, 복합 키 중복 0건.
- 실제 보상 비교로 19개 후보 정책 채택. 이는 학습 코드의 동작 증거이며 일반적 성능 개선/우월성의 증거가 아닙니다.
- λ별 가중치 곡선, 매장별 전선, 그룹 교차검증 연관 분석, 시나리오별 PNG, CSV/JSON/Markdown 요약 생성.
- 로컬 가상환경의 pip check 통과. Colab 코드 셀은 출력 없는 일반 Python으로 컴파일 검증.

테스트 메서드 하나에 여러 검증 항목이 포함됩니다. 후보 채택 수는 해당 시드·소규모 설정에 한정됩니다. 최종 수치의 연구적 해석은 독립 반복과 별도 실측 검증이 필요합니다.

## 미검증·제약

- 사용자 계정의 실제 Colab 로그인·Drive 마운트·브라우저 위젯 통신·Drive FUSE 저장/동기화는 사용자의 최초 Colab 실행에서 확인해야 합니다. Python 콜백 테스트가 이를 대신하지 않습니다.
- 실제 GitHub 결과 업로드 API 쓰기는 Colab Secrets의 사용자 토큰으로 확인해야 합니다. 테스트에서는 API 흐름과 실패 처리를 모의 검증했습니다.
- KREI 공식 URL 자동 다운로드는 이 Cloud Codex 네트워크에서 프록시 403으로 실패했습니다. 검증 우회나 다른 파일 대체는 하지 않았습니다. 기존 Drive의 원자료 경로를 지정하거나 Colab에서 다운로드를 확인해야 합니다. 실제 원자료 기반 대규모 실험은 아직 실행하지 않았습니다.
- GitHub Actions 설정은 추가했으나 원격 CI 결과를 확인했다고 주장하지 않습니다.
- 새로운 매장으로의 통합 정책 일반화, 실제 만족도 피드백 추정, 인과효과 검증, 전역 파레토 최적성은 구현/입증하지 않았습니다.
