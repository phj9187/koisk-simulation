# 푸드코트 소규모 실행 검증 — 2026-11-03

실제 학교 관측 결과가 아니라 가상 환경의 동작 검증이다. 1개 캠퍼스, 메뉴 12/32개, 제한/전체 탐색, 방문 평균 80명, 학습 2세대×후보 4개, 최종 3개 식사 시간대와 스트레스별 3개 시간대다. 4개 작업, 총 472개 식사 시간대 호출을 완료했다.

- 재고 보존·음수 재고 방지, 사건 시간순 처리, 조리원 중복 사용 방지, 추천 거부 시 시간 손실, 학습 중단/재개 동일성, 설정 지문 변경 검사를 통과했다.
- 동일한 4개 작업을 1개/2개 작업자 방식으로 실행했고 최종·스트레스 결과와 학습 상태가 모두 동일했다.
- 학습량이 작고 독립 캠퍼스가 1개이므로 효과 크기나 정확도 향상을 입증하지 않는다. 아래는 점추정이며 신뢰구간이 없다.

- none 대비 기본+스트레스의 학습 정책 비교 40개 중, 손님 점수가 낮아진 경우 8개, 공헌이익이 낮아진 경우 6개였다. 서로 독립인 통계 표본 40개라는 의미는 아니다.

따라서 추천이 항상 이롭거나 편향을 완전히 제거했다고 결론 내리지 않는다. 실패 조건도 그대로 남겼다.

64개 메뉴·방문 평균 600명에서 6개 정책을 한 번씩 호출한 별도 동작 확인은 약 1.38초였다(이 컴퓨터, 측정 시점 기준). 이때 learned 정책은 학습 전 0 가중치이므로 성능 증거가 아니다. 대규모 Colab 실행 시간을 이 수치로 보장하지 않는다.

대규모 설정은 240개 작업, 약 986,400회 식사 시간대 호출을 계획한다. 대규모 학습은 아직 실행 완료하지 않았다.
