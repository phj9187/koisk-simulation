# 가격대·재고·학습 신호 보완

## 범위와 재현

기존 설정의 생성기·보고 점수는 유지한다. 새 `actor_critic_calibrated_pilot.yaml`과 Colab의 calibrated_pilot에서 새 조건을 켠다. 새 결과는 schema 10이며 이전 실험을 덮어쓰거나 당시 결과를 재해석하지 않는다.

## 예산과 재고

`budget_mode: price_relative`는 기존 예산 난수의 분위수를 유지하면서 예산을 기준 가격의 0.75~1.8배로 변환한다. 관측 객단가가 있으면 천 원으로 환산해 기준으로 쓰고, 없으면 메뉴 가격 중앙값을 쓴다. 객단가는 예산 상한의 관측값이 아니다. 배수는 명시적인 가정이며 구매 불가 고객이 0이 되도록 맞추지 않는다. 재방문 고객에도 같은 변환을 적용한다. 기존 제약별 미구매 로그를 유지한다.

`inventory_mode: demand`는 재료 k별 초기량을 ceil(평균 방문자 × 가정 구매율 × 메뉴별 평균 재료 소모량 × 커버 일수)로 정한다. 구매율 기본 0.7, 커버 1.1일이다. 메뉴 비중은 동등하다는 사전 가정이며 실제 미래 선택을 읽지 않는다. 일별 실현 방문자 대신 알려진 평균을 쓴다. 안전재고의 실측 추정이 아니므로 배수·구매율 민감도 확인이 필요하다. 재고 이월·FIFO·기한 만료 원가·보관비·다음날 보충은 기존 다일 경로를 사용한다. 자동 학습 발주가 아니라 기준 재고 보충이다.

## 학습

- `initial_alpha`는 Dirichlet의 **성분별** 초기 농도다. 10이면 총 농도는 50이다. 기존값은 약 1.193이며 기존 기본 동작을 유지한다. 낮고 높은 농도 모두 비교 가능한 설정이다.
- fixed 정책의 `fixed_candidates`개 궤적을 동일 손님·재고·난수 조건에서 실행한다. 각 λ와 날짜 위치마다 다른 후보의 평균 반환을 기준값으로 써 actor의 잡음을 줄인다. 자기 결과를 기준 평균에서 제외하므로 후보 간 비교를 인위적인 자기 기준으로 축소하지 않는다. 빈 날짜도 위치를 보존해 맞춘 뒤 학습 가능한 행동만 갱신한다. 보고 행에는 첫 후보를 쓰며 최고 후보를 사후 골라 성능으로 보고하지 않는다. 실행 횟수를 비용에 기록한다.
- `normalize_advantage`는 이전 업데이트까지의 advantage 제곱 이동평균으로 actor 신호를 나눈다. 현재 평가 표본으로 보정하지 않으며 통계는 체크포인트에 저장한다. critic의 반환 목표와 보고 점수는 바꾸지 않는다. `advantage_scale`, actor/critic 학습률도 설정 가능하다. 새 preset은 학습률을 임의로 높이지 않는다.
- contextual의 고객별 보상은 최종 목적함수 증가분을 유지한다. 개인 만족도로 대체하면 재고·대기 외부효과와 최종 목적이 달라질 수 있기 때문이다. 주어진 제안이 모두 버그 수정인 것은 아니다.

## 비교 기준

`tools/learning_candidate_benchmark.py`는 균등·극단·무작위 가중치 중 학습용 표본의 평균 목적이 가장 높은 후보를 고른다. 전혀 다른 표본에서 미추천·균등·선택 후보·학습된 두 모델을 비교한다. 전역 상한이 아니며 후보 수와 실행 비용을 함께 기록한다. 최종 평가값으로 후보나 학습 설정을 고르지 않는다.

`tools/shared_policy_comparison.py`는 기존 매장 특징 입력을 쓰는 contextual 신경망 하나와 매장별 신경망들을 비교한다. 두 방식에 같은 학습 표본·λ·총 시뮬레이션 횟수를 적용하고 학습 시 매장 순서를 고정 난수로 섞는다. 평가 중 갱신하지 않는다. 동일 매장의 새 고객 평가이며 미관측 매장 일반화 실험은 아니다. 별도 실험 ID·정책 파일·프로토콜을 남기며 본 실행의 매장별 정책을 공유 모델로 몰래 바꾸지 않는다.

## 수렴 해석

고정 점검에서 초기 모델과 학습 모델의 점수를 함께 남긴다. 기존 창 전체의 가중치·점수 안정성을 만족해도 모든 정책의 평균 초기 대비 개선이 1e-6을 넘지 않으면 `stable_without_improvement`로 표시하고 수렴을 이유로 중지하지 않는다. 1e-6은 수치적인 기술 기준이며 통계적 유의성이나 실전 개선의 증거가 아니다. λ별 점수 원자료와 모델별 평균을 함께 확인해야 한다.

## 유지한 평가 정의

가격 성분은 경제성을 뜻하는 `1-가격/예산`으로 유지한다. 이를 맛/가격으로 바꾸면 맛을 중복 평가하고 평가 목적 자체가 달라지므로 이번 수정에 섞지 않는다. 미구매 고객의 전체 방문자 기준 0점도 유지해 포기 고객이 많은 정책을 유리하게 만들지 않는다. 미구매·대기포기·구매율·실제 순이익과 성분별 결과를 함께 분석한다. 어떠한 수정도 추천의 양의 효과를 보장하지 않는다.
