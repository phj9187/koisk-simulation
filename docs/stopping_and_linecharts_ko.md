## 그래프가 보여주는 것

- 평가 가중치 α·β는 연구자가 정한 고정 기준이다. AI가 학습하는 가중치 w와 다르다.
- `evaluation_평가기준.png`: 고정·상황별 모델 각각의 고객 C, 가게 S, 종합 R 평가 점수 선그래프. 최신 동결 평가 주기의 λ별 곡선과 가상 날짜별 추이를 보여준다.
- `evaluation_functions.csv`: 매장·평가 기준·모델별 λ 평가 곡선. 주기를 섞어 평균내지 않고 가장 최근 평가 주기를 사용한다.
- `evaluation_learning_curves.csv`: 날짜·학습/검증/평가 단계·매장·기준·모델별 점수. 고객과 λ 표본이 바뀌므로 이 그래프의 평탄함만으로 중지하지 않는다.
- `recommendation_weight_functions.csv`: 마지막 모델에 동일한 기준 고객·재고·혼잡 상태를 넣었을 때의 5개 추천 가중치와 λ 관계.
- `index.html`: 매장·기준·모델 선택이 가능한 선그래프. 인터넷 연결이나 외부 JavaScript 라이브러리 없이 열린다.

기존 실험도 학습 상태를 변경하지 않고 `python -m kiosk_research.linecharts --root 저장루트 --experiment 실험ID`로 시각화할 수 있다. 체크포인트와 결과 파일의 체크섬을 검증하고 읽기만 한다. 새 코드로 기존 실험의 학습 재개를 우회하는 기능은 아니다.

## 이후 누적 실행의 조기 중지

새 `continual` 설정에서는 조기 중지를 기본으로 켠다. 독립 반복 실험에는 적용하지 않는다. 모든 매장·평가 기준·모델 정책이 아래 조건을 함께 만족해야 전체 실험을 중지한다. 일부만 안정돼도 나머지 모델의 학습을 멈추지 않는다.

1. 검증·평가의 동결 날짜를 제외하고, **100번의 실제 학습 날짜에 걸친 전체 구간**을 본다. 양 끝만 비교하지 않으며, 101개 연속 가중치 스냅샷이 필요하다.
2. 매장별 3개 고정 고객·재고·혼잡 상태와 λ 5개에서 추천 가중치 함수를 평가한다. 서로 다른 날의 평균 고객 구성을 비교하지 않는다. 원시 θ는 softmax의 동치 표현 때문에 직접 비교하지 않는다.
3. 전체 구간에서 각 가중치 성분의 최대−최소 범위를 구하고 그 합의 절반을 계산한다. 이는 구간 내 어떤 두 시점 사이의 총변동 거리(TV)의 보수적 상한이다. 모든 고정 입력에서 이 상한이 **0.01 이하**여야 한다.
4. 별도 난수 이름공간의 고정 고객 3세트와 λ=0, 0.5, 1로 평가하는 **중지 판정 전용 점수**도 100학습 날짜 전체에서 최대−최소가 **0.01 이하**여야 한다. 이 검증은 5학습 날짜마다 실시하며 양 끝을 포함한 최소 21개 평가 지점이 필요하다. 최종 평가 자료는 중지 판정에 쓰지 않는다.
5. 조건 충족 날짜에 `converged` 상태를 저장하고 체크포인트·모델·보고서·선그래프를 생성한 뒤 중지한다. 재개 시 같은 수렴 이력을 읽고, 파일 손상·다른 실험의 이력은 거부한다. 방문자 수가 0인 실행을 수렴의 증거로 취급하지 않는다.

중지 허용치는 `convergence_tolerance`, 구간 길이는 `convergence_window`, 검증 간격은 `convergence_probe_every`로 설정한다. 최초 판정은 기본 설정에서 105번째 학습 날짜에 가능하다. 동시에 0.005·0.01·0.03 기준에서 안정된 정책 수를 저장해 허용치 민감도를 비교한다.

## 1%p의 근거와 한계

문헌이나 라이브러리가 이 시스템에 통용되는 ‘정답 오차율’을 제공하지는 않는다. SciPy의 차분진화는 목적값의 분산에 절대·상대 허용치를 결합하고, scikit-learn은 독립된 검증 점수와 인내 구간을 이용한다. 이를 그대로 이 알고리즘의 수렴 보장으로 옮기지 않는다.

여기서는 추천 특징 x가 모두 [0,1]이고 추천 가중치 w의 합이 1인 구조를 이용한다. 두 가중치 w, v에 대해

`|w·x − v·x| ≤ 0.5 × Σ|w_i − v_i| = TV(w,v)`

이므로 TV≤0.01이면 같은 메뉴·상황에서 정규화 추천 점수가 1%p 이상 변하지 않는다. 이 수학적 해석이 있는 보수적인 연구 운영 기준으로 0.01을 선택했다. 작은 가중치를 분모로 삼는 상대 오차율은 0 근처에서 폭발하므로 쓰지 않는다. **3%가 과학적으로 틀리고 1%가 실증적으로 최적이라는 뜻은 아니다.**

작은 점수 차이로 메뉴 순위가 바뀔 수 있으므로 위 상한만으로 실제 선택·고객 성과 안정성을 보장할 수 없다. 그래서 별도 검증 점수 조건도 함께 요구한다. 세 가지 고정 상황과 유한 λ 격자에서의 안정성은 입력 전체에서의 안정성, 전역 최적점 도달, 실제 인간 만족도 오차를 입증하지 않는다. 중지 판정 세트를 반복 사용하므로 최종 효과 검증에는 별도의 설문·최종 평가가 필요하다.
