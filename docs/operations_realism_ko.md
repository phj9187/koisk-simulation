# 운영 현실성 보완과 검증 한계

새 operations_pilot은 기존 비교 설정을 남긴 채 운영 가정을 개선한 별도 preset이다. schema 11과 새 실험 ID를 사용한다. 과거 실험은 당시 코드를 사용해야 한다.

## 수정한 구조

- 메뉴를 살펴본 뒤 구매를 포기해도 키오스크 탐색 시간은 점유한다. 줄에 서기 전 또는 서비스 전에 인내심이 끝난 손님은 점유하지 않는다. 대기 포기와 실제 자원 사용을 분리했다. 구매하지 않은 손님에게 결제시간을 부과하지 않는다.
- 구매가 가능한 메뉴라도 취향·가격·대기 효용보다 외부 대안이 좋으면 떠나는 outside option을 추가했다. 계수는 관측되지 않아 기본값 null(비활성)이다. 다른 매장 선택을 별도 공간·경쟁 모형으로 재현한 것은 아니다.
- 최대 효용 선택에 사용하는 오차를 표준 Gumbel 방향인 -log(지수 난수)로 선택할 수 있다. 기존 log(지수 난수)는 호환성 모드로 유지한다. 추천 수락식은 여전히 선언된 가정이며 실측 추정식이 아니다.
- 주문 마감 이후에는 새 주문을 받지 않는다. 주문 중 마감을 넘긴 손님도 별도로 집계한다. 이미 접수한 조리는 마감 후에도 끝내고 추가 소요시간을 기록한다. 중도 포기는 탐색시간만 차지하고 조리·재료를 차감하지 않는다.
- 구매 고객에만 결제시간을 더한다. 새 preset의 0.3분은 실측 평균이 아니라 민감도 분석을 위한 가정이다.
- 초기 재고를 모두 새 제품으로 두는 대신 유효기간 안에서 나이가 섞인 코호트로 시작하는 옵션을 추가했다. 오래된 코호트부터 사용한다. 균등 나이 분포 역시 실제 재고 조사값이 아니다.
- 재료별 유통기한 사전과 여러 날의 배송 lead time을 지원한다. 발주량은 보유량뿐 아니라 운송 중 재고도 빼서 계산한다. 부분 미입고분은 다음 발주에서 다시 고려한다. 실제 재료별 자료가 없으므로 기본 유통기한과 배송 1일을 더 정밀한 실측값이라고 주장하지 않는다.
- 새 preset은 7일 에피소드로 늘려 3일 안의 재고 수명 경계에만 의존하는 영향을 줄인다. 여전히 독립 에피소드 사이에는 초기화하므로 무한기간 매장 운영 모형은 아니다.

## 유지되는 범위

키오스크 1대, 메뉴당 대표 재료 1종, 조리사 1인이 메뉴 전체 조리시간 동안 점유되는 모형이다. 다중 키오스크·여러 재료의 레시피·동시 조리 설비·직원 교대·배달 주문·여러 명의 일행·반품과 결제 실패는 재현하지 않는다. 단순히 변수만 추가하면 물리적인 시간 순서가 깨질 수 있으므로 검증 없는 다중 자원 기능을 넣지 않았다. 관측 좌석·매출 비중을 손님 좌석 이용률로 그대로 바꾸지도 않았다. 평가 점수는 관측 만족도나 실측 이익과 별도로 본다.

## 실제 적합성 확인

공개 자료는 매장·수요의 근거지만 개별 주문 시각·포기·주방 대기·폐기 연령 자료가 아니다. 따라서 코드 검사가 통과했다고 현실 적합성이 입증된 것은 아니다. 밖에서 안 산 비율이나 결제시간을 실제와 같다고 선언하지 않는다.

`tools/validate_observed_operations.py`는 별도 검증 기간의 실제·시뮬레이션 일별 CSV를 같은 날짜/매장으로 맞춰 비교한다. 필요한 열은 date, store_id, visitors, orders, mean_total_wait_minutes, expired_units, net_profit이다. 빠진 매장·날짜는 조용히 제외하지 않고 오류로 처리한다. 주문 건수는 현재 손님당 단일 주문 모형과 같은 기준으로 집계해야 한다. 시간은 방문부터 음식 완료까지의 분, 금액은 같은 단위와 비용 범위, 폐기는 같은 재료 단위여야 한다. 검증 데이터를 계수 선택에 다시 쓰면 독립 검증이 아니다.

## 방법론 근거

- SimPy 공식 Bank Renege 예제는 자원 획득과 인내시간 만료를 별도 사건으로 다룬다: https://simpy.readthedocs.io/en/4.1.0/examples/bank_renege.html
- Train 등의 논문은 예상 속성과 실제 경험 속성이 다른 선택·평가를 구분한다: https://eml.berkeley.edu/~train/papers/welfare.pdf
- NIST 모델 검증 지침은 잔차 등 여러 진단으로 자료 적합성을 확인한다: https://itl.nist.gov/div898/handbook/pmd/section4/pmd44.htm

위 출처가 결제 0.3분, 유통기한 3일, 구매 포기 계수 같은 매장별 값을 뒷받침하는 것은 아니다. 계수는 별도 관측과 민감도 분석이 필요하다.
