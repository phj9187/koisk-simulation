# 추천·평가 함수와 실행 모델 점검 (2026-10-26)

구현을 schema 3으로 보완했습니다. 연구 가정의 타당성을 실측으로 입증한 결과가 아니라, 비교 논리와 구현 일관성을 점검한 결과입니다.

## 수정 내용과 근거

| 발견한 문제 | 수정 | 근거 |
|---|---|---|
| 평가에는 가격 여유가 있지만 추천에는 직접적인 가격 항목 없음 | 다섯 번째 추천 특성으로 가격 여유 추가 | 동일한 맛·마진의 메뉴도 고객 예산 대비 부담으로 구분 가능 |
| 추천 마진·재고·대기 척도가 다른 임의 상수에 의존 | 메뉴 기준 정규화, 실제 평가와 공통 측정 정의 사용 | 단위 차이 때문에 가중치 해석이 바뀌는 문제 완화 |
| 추천 대기 특성에서 키오스크 대기·결정시간 누락 | 수락을 가정한 도착→완료 예상 시간을 사용 | 평가의 실제 도착→완료 시간과 의미 일치 |
| 초기 위험 재고가 없으면 재고 개선 점수가 1이 됨 | 0점과 적용 여부를 기록 | 개선하지 않은 성과를 보상하지 않음 |
| 평가 계산이 시뮬레이터 내부에 결합 | 평가 전용 모듈과 범위·계수 검증 추가 | 정책 파라미터 없이 관측 성과를 독립적으로 재평가 가능 |
| 요약에서 평가 구성 항목 누락 | 다섯 원시 구성 점수와 응대 비율·위험 적용 비율 보존 | 가정에 대한 민감도와 부작용을 해석할 근거 확보 |
| 모든 매장의 공통 λ 성과만 통계 비교 | 매장별 전선 HV의 동일가중 평균 통계 추가 | 가게별로 서로 다른 λ가 필요한 맞춤형 연구에 대응 |
| 선택 API가 최종 평가·혼합 시나리오도 수용 | phase 및 단일 시나리오/매장/반복 검사 | 최종 평가를 이용한 선택과 비교 기준 혼합 방지 |
| 호출자가 원래 설정을 변경하면 실험에도 영향 | 생성 시 설정 깊은 복사 | 시작 시 기록한 연구 조건 유지 |
| 0인 초기 재고도 최소 1로 생성 | 0 보존 | 없는 재고를 만들지 않음 |

추천 정책은 5차원 softmax 가중치를 출력합니다. 고정 15개, 상황별 135개 파라미터이며 신경망으로 바꾸지는 않았습니다. 파라미터 차원 차이 때문에 같은 시뮬레이터 호출 예산이 같은 학습 난이도를 뜻하지 않습니다.

## 전반 점검 범위

- 함수: λ 끝점, 가중치 합, 평가 독립성·단조성, 가격 신호, 대기 증가, 무위험 재고, 미응대 처리.
- 실험: 공통 난수, 원본 매장 불변, 동일 호출 예산, 검증·최종 평가 동안 학습 동결, 반복마다 초기화.
- 통계: 비지배 판정·HV, 공통 λ와 매장별 전선 구분, 반복 단위 부트스트랩, 검증 제약 선택.
- 저장: 중단 재개와 연속 실행의 동일성, 매장 부분 복구, 손상 체크포인트 대체, 중복·동시 실행 차단.
- 연결: 노트북 코드 구문, 위젯 Python 시작/중지 콜백, GitHub 업로드 API 모의시험·인증 실패, 원자료 SHA 검사, 원본 소스 보존.

자동 테스트 27개 통과. 로그는 `/workspace/kiosk-audit-20261026/tests.log`입니다. 별도 8매장·3시나리오·2모델·5반복 소규모 실행으로 중단 재개 및 CSV·JSON·PNG 내보내기를 확인했습니다. 최종 실행 ID·코드 SHA·행 수는 `/workspace/kiosk-audit-20261026/verification.json`에 기록했습니다.

## 해석 한계와 다음 연구

- α·β와 고객 행동 모형은 여전히 가정입니다. 가중치를 자동으로 바꾸어 성적을 올리지 않습니다. 실제 만족도 계수 추정에는 설문·선택·재방문 자료와 별도 검증이 필요합니다.
- τ=25분, affinity 내부 0.7/0.3, 고객 자체 선택·수락 모형도 민감도 분석 대상입니다. 0~1 척도 일치만으로 고객·가게 효용이 사회적으로 동등해지는 것은 아닙니다.
- 재고 감소는 폐기 손실의 대리 지표입니다. 재고 이월, 실제 유통기한, 폐기 비용, 수요 예측은 아직 없습니다. 부의 이익은 점수에서 0으로 절삭되므로 원시 이익도 확인해야 합니다.
- 유한 무작위 탐색이며 전역 최적성·완전한 파레토 전선·상황별 모델 우월성을 보장하지 않습니다. 5회 짧은 반복은 기능 검증용입니다.
- 매장별 모델입니다. 새 매장 전이, 매장 특성의 인과효과, λ별 독립 최적화 기준선은 후속 연구입니다.
- Colab 실제 브라우저 위젯·Drive 권한·GitHub 실제 토큰 업로드는 이번 로컬 검증 범위가 아닙니다. KREI 실자료 대규모 실행도 수행하지 않았습니다.
